3-2-1 备份方案

The 3-2-1 backup strategy simply states that you should have 3 copies of your data (your production data and 2 backup copies) on two different media (disk and tape) with one copy off-site for disaster recovery

3-2-1的备份策略只是指出，您应该在两个不同的媒体（磁盘和磁带）上拥有3份数据副本（您的生产数据和2份备份副本），其中一份副本副本以供灾难恢复

Vim操作

vim3种模式：命令模式、输入模式、命令行模式 首次进入是命令模式

切换模式：

  1. 命令模式：esc
  2. 输入模式：i 再按 esc 回到命令模式
  3. 命令行模式：: 再按 esc 回到命令模式

常用操作

显示文件信息

显示行号 :set nu
取消显示行号 :set nonu

移动光标

上下 k j
左右 h l
光标下移20行 20j
到文件最上行 gg
到文件最下行 G
行首0
行尾$
上/下翻页 ctrl+f ctrl+b
跳到行数:

输入模式光标移动

切换光标为输入/替换模式，光标将变成竖线/下划线 Insert
方向键移动光标 ↑↓←→
移动光标到行首/行尾 HOME/END
上/下翻页 Page Up/Page Down

编辑

切换插入模式：i
插入行并编辑：o
保存：:w
退出：:q
退出不保存：:q!
退出并保存：:wq
撤销上次操作：u
重做上一次撤销的操作：ctrl+r
复制行：yy
复制20行 20yy
粘贴到光标下行：p
粘贴10次10p
粘贴到光标上行：P
删除行：dd
删除50行 50dd
删除所有行 gg dG
删除字符：x
重复上次动作：.

搜索替换

向下搜索：/
向上搜索：?
重复前一个搜寻的动作：n
搜索第10个搜索结果：10n
反向进行前一个搜寻动作：N
全局替换：:s/old/new/g
全局替换并保存：:%s/old/new/g
